# 喵星成长屋：小猫游乐场与共同成长方案

> 讨论记录：2026年11月3日；版本：v0.1。
> 状态：第一段自由玩、落地时机评价及一个“绕垫子引猫”短挑战已于2026年11月3日14:05按用户授权部署到原站点，技术验收通过；代码尚未提交或推送。其他关卡、成长解锁和存档尚未开发，是否好玩仍需孩子试玩验证。
> 保存约定：以本地 `docs/cat-playground-plan.md` 为方案主档，后续在当前项目内增量更新，不同步腾讯文档。
> 核心结论：从“完成任务养猫”转成“我和这只猫一起成长”。现实任务提供支持，小猫本身必须好玩。不能把增加在线时间或聊天次数当目标。

## 一、背景与已知信息

- 家长反馈：任务系统暂时稳定，但猫互动和可玩性不足，担心难以长期吸引孩子。
- 目标孩子目前10岁；家长表示动手操作、闯关、布置、收集、讲故事都喜欢。
- 目前主要行为是完成任务、喂猫粮，对话较少。这是家长提供的观察，不是埋点统计。
- 年龄与兴趣说明值得做玩法试玩，但不足以证明具体方案会好玩；不得将年龄概括为所有10岁儿童的偏好。
- 本轮只做设计分析与讨论记录，不修改现有任务、连击或星星规则。

## 二、当前玩法的原子拆解与证据

当前核心动词是“点”：做任务赚星星，花星星喂食或买道具，点猫和道具观看反应。

| 现有能力 | 实际体验 | 缺口 |
|---|---|---|
| 点击猫、抚摸 | 跳跃、气泡、少量心情变化 | 没有连续抚摸操作或技巧 |
| 喂食 | 选择放碗位置，猫自动走去吃 | 主要是资源消费，不是独立玩法 |
| 毛线球 | 猫自动追逐、球随机移动 | 孩子是观众，没有主动操控、目标或难度 |
| 道具布置 | 拖拽、保存位置、切换壁纸 | 有表达空间，但组合尚不改变玩法 |
| 等级 | 累计星星推动升级 | 新动作解锁提示尚未实际兑现 |
| 庭院 | 昼夜变化的背景 | 不是可进入的探索场景 |
| 猫聊天、信箱 | 对话与任务审核反馈 | 缺少由实际游戏经历产生的自然话题 |

主要源码核对入口：frontend/src/views/KidHome.vue（自动互动、拍猫、喂食、道具、庭院、聊天）；frontend/src/components/CatSprite.vue；backend/internal/store/store.go；backend/internal/engine/settle.go。以上来自讨论当日的只读核对，不代表未来版本永远如此。

MDA诊断：现有机制以点击触发与资源交换为主，动态主要是重复观看反应，体验偏向任务奖励工具。操作反馈可爱但变化不足，有意义的选择与可练习的挑战偏弱。长期攒星目标存在，短期好玩操作与中期猫能力变化不足。

## 三、产品主线：一个核心，三层动机

不同时建设操作、收集、装修、故事四套独立系统。先以“小猫游乐场”的动手短挑战为核心，让其他兴趣为同一个核心提供变化。

1. 这次想再试一下：亲手逗猫，尝试更好的时机与路线。
2. 下次想看看变化：猫获得新的可用本领，留下共同经历。
3. 这是我的小世界：收集不同玩法的玩具，布置属于自己的场地。

建议循环：亲手互动 → 明确反应 → 发现技巧 → 一起学会新本领 → 玩具和场地出现新玩法 → 下一次想尝试。

核心乐趣：它因为我做了什么而变化，而且我的猫和我有独特的共同经历。随机说“主人真棒”不等于关系成长。

不把聊天次数少当故障。猫可通过动作、短句、主动邀请表达自己；真正有事发生时再聊天。聊天是陪伴的补充，不是主要留存手段。

## 四、首个拟议玩法：引猫扑玩具

### 核心动词

“引”：孩子控制玩具位置与节奏，引导猫完成短挑战，而非点一下让猫自动演完整段动画。

### 四条基础规则（候选，尚未细定）

1. 手指拖动玩具，猫会追踪，但不能瞬间到达。
2. 停住玩具，猫表现出准备扑跃的姿态，反馈必须清楚。
3. 在合适距离和时机松手，让猫扑到；扑空可以马上再试，不扣钱或已得资源。
4. 场地障碍改变路线，同样操作需要调整；猫不会替孩子自动通关。

涌现复杂度来源：距离、时机、路线的组合，不是按钮数量或随机不听话。短期挑战是“这次如何扑到”，长期追求是“我们能玩出什么新花样”。实时操作以确定规则判定；AI可描述事后趣事，不参与实时成功判定。

### 玩家成长与猫成长

- 孩子成长：观察姿态、选择路径、掌握停顿和释放时机。
- 猫成长：获得钻箱、探头、躲藏等新的可用互动，改变后续能玩的内容。
- 不能通过升级将猫变成自动通关机器，避免成长后再次退化为观看动画。

## 五、最小试玩范围

先做一个逗猫玩法、三个逐步变化的小挑战、一项真正可用的新本领。每个挑战以约一分钟作为初步试玩尺度，不是强制计时或上线指标；难度和时长根据试玩调整。另有不计分的自由玩耍。

| 候选挑战 | 孩子需要发现什么 | 新增价值 |
|---|---|---|
| 第一次扑到羽毛 | 停顿使猫准备，距离影响扑跃 | 证明基本操作和反馈有趣 |
| 绕过垫子再扑 | 不仅拖到终点，还要选择路线 | 增加空间判断 |
| 纸箱里的羽毛 | 路线与扑跃组合 | 引出钻箱、探头互动 |

第三个挑战的拟议成果不是“经验加10”，而是房间中的纸箱以后真的能用于躲猫猫。是否采用这一解锁条件，仍需细化确认。

第一轮不扩任务系统、不新增币种、不做庞大技能树或多地图。先验证基本逗猫操作；若手感和反馈不吸引孩子，不继续堆收集与剧情。

## 六、与任务系统、星星和陪伴的关系

- 基础玩具和基础陪伴始终可用，可重复玩，不消费门票或次数。
- 现实任务星星可以购买更多玩具和布置，拓宽选择，不用“不给玩”强迫做任务。
- 首轮不让小游戏反复产星星，不绕开现有现实任务奖励闭环。
- 新玩具应该有不同玩法，而不只是不同颜色；具体商品与价格未设计、未批准。
- 已学会本领不因不登录退步；不增加强制每日猫训练，不把养猫变成第二份作业。
- 不以饥饿伤害、离开后悲伤、限时错过奖励等压力催促孩子回来。
- 有自然结束点，追求孩子主动回来短玩，而不是最大化在线时间。

## 七、优先级与明确不做清单

| 优先级 | 内容 | 条件 |
|---|---|---|
| 高 | 亲手逗猫的操作、清晰即时反馈 | 首轮验证核心 |
| 高 | 少量渐进挑战、一项可用新本领 | 不以经验条替代能力变化 |
| 中 | 家具组合与自由场地布置 | 核心玩法验证后再设计 |
| 中 | 共同纪念册、猫的偏好、简短情境 | 基于真实互动，不制造虚假经历 |
| 低 | 更多服装、地图、长剧情、复杂聊天 | 非首版范围 |

暂缓：商品扩容、排行榜、抽奖、更多等级条、新货币、签到奖励、庞大技能树、同时建设多个小游戏。

避免四个风险：过度复杂、数值堆砌、无脑重复、隐藏规则不透明。失败反馈应可理解、有恢复空间；不能随机卡住孩子或靠数值压制制造难度。

## 八、试玩验收：不用奖励诱导判断好不好玩

以下是观察问题，不是已经达成的事实或强制KPI：

1. 不给星星时，孩子是否愿意再试一次？
2. 是否主动换一种操作，而不是乱点或等动画？
3. 是否能说出“我发现停一下它就会……”这类明确技巧？
4. 是否记住猫获得的变化，并想在房间里使用？
5. 新鲜感过去后，是否仍主动打开玩，或者想改场地？
6. 是否可以自然结束，不因奖励压力纠缠继续？

观察区分操作不清楚、挑战太易或太难、仅动画新鲜感、确实学到技巧等情况。最初几十秒确认能理解输入；几次试玩观察“再来一次”；后续几天再看回访。不因为一次开心就宣称长期吸引力已经解决。

## 九、参考结构

- Flappy Bird：借鉴少量操作、清晰反馈、可练习时机的结构，不借高压惩罚或死亡重开。
- 动物森友会：借鉴属于自己的世界、布置能留下变化与发现感，不复制大规模经济和内容系统。官方玩法介绍：https://nintendo.com/games/detail/animal-crossing-new-horizons-switch/

这些是结构参照，不是同龄儿童留存数据或本产品成功保证。

### 本轮修复的验收问题

- ready小幅抖动越出距离边界必须撤销绿灯，不能提示能扑却判失败。
- 抓住后立即重按或等待恢复再重按都能开始下一轮，扑空后也恢复可再次蓄势的距离。
- 60px触控热区按实际缩放尺寸预留安全边界，避免手机边缘裁切。
- 旧walkTo异步、RAF、定时回调使用代际守卫；相机从实际渲染位置冻结，防止退出猫跑出屏幕。
- 手机状态提示换行曾使居中面板/场地位移，导致松手坐标变化、正确ready被误判早松；固定状态区域高度后，ready到pounce的场地矩形保持不变。
- 横屏采用左右分栏，退出与所有操作可见；预览父级样式限定自身section，避免污染子组件根节点。

## 十二、时机评价与单路线挑战（2026年11月3日，未上线）

### 范围与结合方式

- 同一“和猫玩”入口中分“自由玩”和“小挑战”，默认自由玩；两种均免费、无体力/星星消耗，不产星星，不要求先完成学习任务或喂食。
- 本轮只一个“绕垫子引猫”挑战。猫脚必须经过上方脚印，再引到目标圈内扑到羽毛；不强制perfect评级才能通关。直接跳目标、只将羽毛拖过脚印、穿过垫子均不能完成。
- 垫子碰撞按猫占地扩框，跟随与整个扑跃路径都检测，不只看终点、不自动寻路。绘制路线和目标提示，难度来自引导路径而不是刷成功次数或缩窄时间窗。
- 完成显示“挑战完成”和本次时机评价；再挑战会重置，重复不发资源。评价、经过脚印、完成状态仅在组件内存，关闭后不保存。没有新增数据库/API/localStorage/统计，也没有成长解锁。
- 后续若接入成长，优先首次完成解锁可用新互动，现实任务仍提供星星和玩具选择；具体能力、解锁与持久化另行确认，本轮不提前搭系统。

### 评价及可调参数

- 松手时按真实ready持续时间取评价，但着地后才公开：未准备=快了，<=0.6秒=时机特别好，<=1.5秒=不错，>1.5秒=慢了一点且仍可成功。太远/太近/路线未完成/垫子阻挡独立提示。
- 输入事件先以与RAF同源的performance.now推进旧阶段，避免将松手前ready时间计入扑跃而提前落地；后台/取消不补发评价或抓取。
